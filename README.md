# 🚀 Space Exploration Quiz

A ten-question space exploration quiz in a single `index.html`. No server, build step, or dependencies.

## Features
- Ten multiple-choice questions with a fun fact after each answer
- Progress bar with a rocket that moves as you advance, plus a live score
- Green pop for correct answers, red shake for wrong ones
- Results screen with an emoji reaction
- Light and dark themes: follows your system setting, with a manual toggle that is remembered
- Keyboard friendly, and respects reduced-motion settings

## Run it
Open `index.html` in any modern browser.

## Smoke test
Open `index.html`, paste `smoke-test.js` into the browser DevTools console, and check the PASS/FAIL output.
